> 适用：ROS 2 Jazzy + Livox MID-360 + 四舵轮全向底盘

## 1. 系统架构

```
MID-360 → livox_ros_driver2 → /livox/lidar
                                   │
                                   ▼
┌──────────────────────────────────────────────────────┐
│ Point-LIO (point_lio)                                │
│  LIO 高频里程计，输出 /Odometry, /cloud_registered   │
└──────────────────────┬───────────────────────────────┘
                       │
                       ▼ /cloud_registered
┌──────────────────────────────────────────────────────┐
│ cpp_lidar_filter                                     │
│  CropBox 挖掉车体 → /cloud_filtered                  │
└────────┬─────────────────────────┬───────────────────┘
         │                         │
         ▼                         ▼ /cloud_filtered
┌──────────────────┐  ┌────────────────────────────────┐
│ pointcloud_to    │  │ small_gicp_relocalization       │
│ _laserscan       │  │  GICP 全局匹配 → /pose          │
│ → /scan (2D)     │  │  TF输出重定向到 /tf_null        │
└────────┬─────────┘  └──────────┬─────────────────────┘
         │                       │
         ▼ /scan                 ▼ /pose
┌──────────────────┐  ┌────────────────────────────────┐
│     Nav2         │  │ robot_localization/EKF          │
│  costmaps        │  │  odom0: /Odometry               │
│  planner         │  │  pose0: /pose                   │
│  controller      │  │  发布 map → odom TF             │
└────────┬─────────┘  └────────────────────────────────┘
         │
         ▼ /cmd_vel_nav
┌──────────────────────────────────────────────────────┐
│ fake_vel_transform                                    │
│  Nav2 角速度 + 小陀螺 spin 叠加                        │
│  发布 base_link → base_footprint_stabilized TF         │
│  → /serial/cmd_vel                                    │
└───────────┬──────────────────────────────────────────┘
            │
            ▼
      串口节点 → 电机驱动
```

### TF 树

```
map ──(EKF)──→ odom ──(Point-LIO)──→ base_link ──(fake_vel)──→ base_footprint_stabilized
```

## 6. 启动流程

```bash
# 1. 启动 Livox 驱动
ros2 launch livox_ros_driver2 msg_MID360_launch.py

# 2. 启动 Point-LIO
ros2 launch point_lio point_lio.launch.py rviz:=False

# 3. 等待 LIO 稳定后，启动核心管线
ros2 launch sentry_bringup core_pipeline.launch.py

# 4. 启动 Nav2
ros2 launch nav2_bringup bringup_launch.py \
  params_file:=/path/to/sentry_bringup/config/nav2_params.yaml \
  map:=/path/to/rm_field.yaml
```

## 7. 注意事项

### 7.1 坐标系统

- `base_footprint_stabilized` 是虚拟帧，始终不旋转，Nav2 在此帧下做纯平移避障
- 绝对不要手动发布 `map → odom` TF，EKF 独占此发布权
- GICP 的 TF 输出被重定向到 `/tf_null`（黑洞），防止和 EKF 抢夺 `map → odom`

### 7.2 小陀螺 (spin)

- spin 速度由行为树通过 `/chassis/target_angular_z` 下发
- fake_vel_transform 将其叠加到 Nav2 的角速度上：`angular.z = nav2_angular + spin_speed`
- 默认 `init_spin_speed = 0.0`，即不自转

### 7.3 速度指令链

```
/cmd_vel_nav (Vx, Vy, Wz) ──→ fake_vel_transform ──→ /serial/cmd_vel
                                  ↑
        /chassis/target_angular_z (spin 叠加)
```

### 7.4 地图

- GICP 需要 `.pcd` 格式点云地图
- Nav2 需要 `.pgm` + `.yaml` 格式栅格地图（global_costmap static_layer）
- 两者是同一场地的不同格式，需分别提供

### 7.5 LiDAR 倒装

- MID-360 倒装后，必须在 URDF 中体现 `base_link → lidar_frame` 的旋转（绕 X 或 Y 轴 180°）
- 否则 Point-LIO 输入颠倒，定位完全错误
- `mid360.yaml` 中的 LiDAR→IMU 外参保持不变（出厂值，相对关系不变）

### 7.6 QoS

- `/scan` 使用 `best_effort`，符合传感器数据标准实践
- 其他话题使用默认 QoS，已验证全链路兼容

### 7.7 编译后必做

- 修改 `cpp_lidar_filter/src/filter_node.cpp` 或 `pointcloud_to_laserscan/src/` 后必须重新 `colcon build`
- 修改 `.yaml` 或 `.launch.py` 不需要重新编译

### 7.8 调参流程

1. **先跑通**：P0 参数（车身尺寸、LiDAR 外参、地图路径）确认无误
2. **调 PID**：从低 Kp 开始，逐渐增大到不振荡的最高值
3. **调速度**：从低速开始逐步放限，确保刹车距离可控
4. **调避障**：观察 costmap 膨胀是否合理，是否误触障碍物

## 8. 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Nav2 启动崩溃，controller 加载失败 | pb_omni_pid_pursuit_controller 未编译 | `colcon build` 该包 |
| 定位漂移/瞬移 | GICP 匹配失败或 EKF rejection 过小 | 检查地图是否加载，增大 `pose0_rejection_threshold` |
| 机器人撞自己 | CropBox 尺寸偏小 | 增大 cpp_lidar_filter 裁剪盒参数 |
| LiDAR 点云上下颠倒 | URDF 中未配置倒装 TF | 检查 `base_link → lidar_frame` 的 roll/pitch |
| /scan 无输出 | pointcloud_to_laserscan 订阅话题不对 | 检查 launch 中 `cloud_in` remap 为 `/cloud_filtered` |
| 串口无指令下发 | fake_vel_transform 输出话题不匹配 | 检查 `output_cmd_vel_topic` 是否与串口节点一致 |
